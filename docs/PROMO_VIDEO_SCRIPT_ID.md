# Higgsfield Promotional Video Script — Spartacus

**Duration:** 45 seconds  
**Primary format:** 9:16 (Reels/TikTok/Shorts); keep the desktop source wide so the UI remains sharp when cropped.  
**Tone:** calm, decisive, cinematic—not noisy productivity.  
**Music:** minimal ambient bed with soft piano/lofi. Use a gentle bell only at the timer transition.

## Main narration

> Too many apps are asking for your attention.  
> Spartacus gives that attention back to you.  
> Start one session. Find the right sound.  
> And remember what you are working for.  
> From a five-year vision, to three-year goals, to this month’s next step—everything stays connected.  
> Choose rain, ocean, a café, or lofi. No feeds. No ads. No distracting video.  
> When you need space, Spartacus becomes a small timer that stays with you.  
> One calm place to take back your time.  
> Spartacus. Focus with purpose.

## Global Higgsfield style prompt

> Cinematic premium desktop-app promo, monochrome black and white interface, calm focused mood, subtle film grain, soft volumetric light, slow controlled camera push-ins and parallax only, high contrast typography, no extra UI elements, no warped text, no new logos, preserve the supplied app screenshot exactly, elegant transitions, minimal ambient sound design.

## Production notes

- Use every screenshot as an **image reference**, not a scene for the model to recreate; this keeps UI text accurate.
- Crop vertically with the scene’s named element in focus. Do not place promotional copy over the timer or goal labels.
- Keep each cut between 3 and 6 seconds. Use only gentle crossfades and slides.
- For a 16:9 version, retain the original composition and place promotional copy in the lower third.
